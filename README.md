# Balatrool - a fanmade HUB with various Balatro-related tools. 
# (Now in Alpha!)


## Functionality

The interface will offer (WiP) the user 4 cards, every of which is responsible for a different Balatro-related task.

- Tracker allows the user to check his golden stake progress, corelating to the achievement Completionist ++. Furthermore, the AI-generated code allows the user directly to convert the changes into a .json or .xls file.
- Balatro Personality includes a quiz and an afore generated personality type, allowing for the user experience to feel personalized.
- Import data allows the user to import data, necessary for selected functions to become available.
- Joker Studio is a simple aid in generating game-accurate representation of cards, helpful for their presentation and/or addition into game files.

## Technology

- GIMP v2.10
- Photoshop
- ChatGPT 5
- Gemini 2.5
